PHP configures it. 3Dmol.js renders it.

A PHP-first integration layer for embedding interactive molecular structure viewers in your applications.

What is PDBViewerPHP?

PDBViewerPHP is a PHP library that simplifies embedding interactive molecular structure viewers in PHP applications. It provides a PHP-side configuration and embedding layer around 3Dmol.js.

Instead of manually writing HTML and JavaScript to initialize a molecular viewer, your PHP application can define the viewer configuration and let PDBViewerPHP generate the required client-side code automatically.

The core idea: Let PHP developers configure molecular viewers without needing deep JavaScript expertise. The library handles generating the proper 3Dmol.js initialization code.

Why PDBViewerPHP?

Without PDBViewerPHP

You need to:

  • Write HTML boilerplate
  • Write JavaScript to initialize 3Dmol.js
  • Configure molecular representations
  • Handle viewer interface controls
  • Manage themes and styling

With PDBViewerPHP

You can:

  • Configure everything in PHP
  • Specify structures, representations, and appearance
  • Let the library generate HTML/JS
  • Focus on your application logic
  • Reuse viewer configurations

PDBViewerPHP is ideal when: Your server application determines how a molecular structure should be initially presented, and you want to configure that from PHP rather than JavaScript.

Architecture

PDBViewerPHP is designed as a configuration and integration layer between your PHP application and 3Dmol.js:

↓

↓
📝

↓
🎨

WebGL rendering engine

PHP Layer (Server-Side)

Handles:

  • Structure selection and data
  • Molecular representation config
  • Color and appearance settings
  • Interface feature availability
  • Theme selection

Browser Layer (Client-Side)

3Dmol.js handles:

  • WebGL rendering
  • Interactive rotation/zoom
  • Molecular visualization
  • User interactions
  • Camera and view controls

Installation

Install PDBViewerPHP via Composer:

composer require saurabhgayali/pdbviewerphp

Then in your PHP application:

use PDBViewerPHP\PDBViewer;
use PDBViewerPHP\Configuration\Structure;
use PDBViewerPHP\Configuration\Representation;

// Create a viewer
$viewer = new PDBViewer();

// Configure structure
$viewer->setStructure(Structure::fromPdbId('1mb3'));

// Add representations
$viewer->addRepresentation(
    new Representation('cartoon', ['color' => 'spectrum'])
);

// Render to HTML
echo $viewer->render();

For detailed documentation and examples: Visit the GitHub repository

Project Status

Current Release: Pre-1.0

PDBViewerPHP is in active development. The API is not yet stable and may change before version 1.0.

What This Project Does

  • ✅ Provides PHP configuration for molecular viewer initialization
  • ✅ Generates HTML and JavaScript for 3Dmol.js integration
  • ✅ Supports common molecular representations and visualizations
  • ✅ Includes viewer interface and theming

Current Limitations

  • Not intended for molecular dynamics visualization
  • Does not handle electron-density maps
  • Not a replacement for PyMOL, ChimeraX, or molecular modeling software
  • Focuses on structure visualization, not advanced analysis
  • API subject to change

Roadmap

Possible future directions include:

  • Improved viewer controls and interactions
  • Measurement and selection tools
  • Structure annotations
  • Sequence/structure interaction
  • Additional molecular rendering engines
  • More viewer themes
  • Framework/CMS integrations
